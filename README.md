### 🌦️ CityClimateApi

A **.NET 8 Web API** providing real-time weather and air-quality information using external APIs.

**Features**

* 🌡️ Real-time weather data
* 🌫️ Air quality information
* 🌍 City-based queries
* 📡 OpenWeatherMap integration
* 🧪 Unit testing with xUnit & Moq
* 📖 Swagger / OpenAPI
* 🏗️ Clean & maintainable architecture

**Stack**

`C#` `ASP.NET Core` `.NET 8` `EF Core` `xUnit` `Moq` `Swagger`
